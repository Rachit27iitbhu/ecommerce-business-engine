# E-commerce Business Decision Engine

An analytics and decision-support application that transforms raw e-commerce transaction data into reproducible metrics, data-quality audits, and deterministic, evidence-based business recommendations.

---

## Problem

E-commerce sellers collect large volumes of transactional data across sales history, order volumes, and customer purchases. However, turning raw transaction logs into concrete operational decisions remains a key bottleneck:

* **Generic Dashboards:** Most tools display aggregated charts (e.g., total revenue, daily orders) without highlighting actionable next steps.
* **Manual Bottlenecks:** Sellers must manually pivot data to locate declining products, identify churning customers, or assess inventory concentration risks.
* **Fabricated Metrics:** Many modern decision tools generate unverified ROI projections, speculative revenue lift numbers, or LLM-hallucinated figures that cannot be traced back to underlying data.

---

## Solution

The **E-commerce Business Decision Engine** acts as an automated decision-support pipeline. It ingests transaction logs, validates data integrity, computes core KPIs, and executes deterministic rule-based algorithms to generate concrete operational recommendations.

Every metric and recommendation generated by the engine includes transparent, reproducible evidence derived directly from the underlying dataset—with zero fabricated ROI or unverified business-impact estimates.

## Quickstart Guide

### Prerequisites

* Python 3.11+
* Node.js 18+ and npm

### 1. Environment Setup

Clone the repository and install the Python dependencies:

```bash
pip install -r requirements.txt

```

### 2. Generate Sample Dataset

Generate the default synthetic dataset (10,000 transaction rows with labeled data-quality edge cases):

```bash
python data/generate_sample.py

```

*Note: The generated sample dataset contains synthetic data for evaluation purposes and does not represent real commercial operations.*

### 3. Run Backend API

Start the FastAPI backend server:

```bash
uvicorn backend.main:app --reload

```

The API will be available at `http://localhost:8000`. Interactive documentation can be accessed at `http://localhost:8000/docs`.

### 4. Run Frontend Dashboard

In a separate terminal window, set up and run the React frontend:

```bash
cd frontend
npm install
npm run dev

```

Open your browser to the local Vite dev URL (typically `http://localhost:5173`).

## Data Schema & Custom Dataset Integration

The application operates on transaction-level CSV data containing the following minimum standard columns:

| Column | Type | Required | Description |
| --- | --- | --- | --- |
| `order_id` | String | Yes | Unique order identifier |
| `order_date` | Date/Timestamp | Yes | Date/time of purchase |
| `customer_id` | String | Yes | Unique customer identifier |
| `product_id` | String | Yes | Unique product identifier |
| `quantity` | Numeric | Yes | Number of units purchased |
| `unit_price` | Numeric | Yes | Selling price per unit |
| `category` | String | Optional | Product category grouping |
| `discount` | Numeric | Optional | Discount applied to order |
| `cost` | Numeric | Optional | Product unit cost |

### Replacing Sample Data

To analyze custom or real transaction logs:

1. Format your transaction dataset to match the column schema above.
2. Replace `data/sample_orders.csv` with your CSV file.
3. Restart the backend service or invoke the API endpoints.

## Limitations

* **Observational Data Only:** Recommendations are derived strictly from historical observational trends. They highlight past momentum shifts, sales drop-offs, and churn patterns, but do not prove causal business impact or guarantee future sales improvements.
* **Static Rule Heuristics:** The system utilizes explicit rule-based thresholds (e.g., 30% velocity decline, 60-day customer inactivity) rather than dynamic dynamic machine learning models.
* **No Predictive Financial Growth:** The application explicitly avoids calculating or claiming speculative financial growth, potential ROI percentages, or unverified cost savings.
